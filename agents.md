### 🧰 Technologies to Use

The project is built using the following technologies and tools:

**Frontend:**

* **React.js** – for building the user interface and page components.
* **React Router DOM** – for page navigation and routing.
* **Tailwind CSS** – for fast, clean, and responsive styling.
* **Axios** – for handling API requests between frontend and backend.
* **Recharts / Chart.js** – for displaying financial data and visual reports.

**Backend:**

* **Node.js** with **Express.js** – for building the RESTful API and handling server-side logic.
* **JWT (JSON Web Tokens)** – for authentication and secure user sessions.
* **bcrypt.js** – for password hashing and user security.
* **dotenv** – for environment variable management.

**Database:**

* **PostgreSQL** – as the main relational database for storing user, profile, and expense data.
* **Prisma** or **Sequelize** (ORM) – for managing models, migrations, and database queries.

**Development & Deployment Tools:**

* **Git & GitHub** – for version control and collaboration.
